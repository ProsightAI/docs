# ProsightAI

**Contactless physiological intelligence using standard video.**

ProsightAI is developing software that uses standard cameras to support contactless physiological sensing.

This repository contains selected public documentation only.

## Public Documentation

**View the public documentation:** https://prosightai.github.io/docs/

The public documentation covers:

* Contactless physiological measurement
* Measurement quality, confidence, labeling, and withholding
* Human review and safety boundaries

## Important

This repository is intentionally limited.

It does not contain ProsightAI source code, models, algorithms, infrastructure, datasets, customer data, internal architecture, research experiments, product roadmaps, domain configurations, or other proprietary implementation details.

ProsightAI outputs provide physiological information and context. They are not a substitute for professional medical advice or human decision-making.
